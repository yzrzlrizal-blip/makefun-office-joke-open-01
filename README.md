A one-line joke about office life, written for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty. The program writes the joke in `entry.txt` to the grader's output directory as `entry.txt` — a single line, 123 characters, about asking everyone to stop replying all and getting out-of-office replies from a man who retired in 2019.

## Run it

```sh
python3 main.py
```
